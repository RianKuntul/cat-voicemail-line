The funniest voicemail greeting a cat would record. Miso can't come to the
phone — he's busy knocking your glass off the table — and leaving a message
only earns you a 4 a.m. wake-up call demanding food.

## Run

```sh
node main.ts
```

Writes the entry to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`).
